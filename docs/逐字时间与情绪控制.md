# 逐字时间与情绪控制

本轮已将 51 句、325 个字改为独立时间候选。重新使用逐字 token 做音轨 attention 对齐，不再将多字 token 均分；第一主歌中模型坍缩的一句通过更宽的音频上下文重算。当前数据没有 `estimated-line-distribution` 回退。

每个字分别记录：

- `start / end`：起唱与唱止候选，实际时长各不相同。
- `appearAt / disappearAt`：画面中的出现、退场，作为编排值与歌声时间分开保存。
- `emphasis`：0–2 的强调强度，不使用模型置信度冒充情绪强度。
- `verified`：只有人工在页面勾选后才表示试听确认；自动结果保持 false。

长音使用持续高亮和抬升，跟随本字结束时间释放；短音缩短动作，字间换气没有活动高亮。已唱完的字可继续停留，后续的字按各自出现时间显示。暂停和拖动仍以音轨 `currentTime` 重算画面。

页面下方“逐字校准”支持选择句子、点击单字、编辑四个边界、20ms 微移、按当前时刻标记、单字及前后 0.4 秒循环试听、强调强度、单字还原与确认。直接输入框步长为 0.01 秒，这表示操作步长，不代表模型准确度达到 10ms。原有全局／单句偏移和浏览器保存记录保留；逐字修改与确认状态新增到同一存储记录，导出时会同时输出。

## 可信范围

当前候选最短唱音约 0.08 秒，最长约 1.68 秒；317 字使用逐字对齐，8 字采用扩大上下文后的逐字对齐。模型评分低于 0.35 的有 164 字，该分数不是经过校准的“正确概率”。首字仍使用粗起点提示消除 DTW 的前导静音，尾字边界也可能包含换气或余音。尚未进行全曲逐字人工听验，不能把数值精细等同于全部准确。

自动对齐与视觉默认时长均为制作起点。每轮重复的歌词都分别对齐自己的音频，不将另一轮的单字时长复制过来。
