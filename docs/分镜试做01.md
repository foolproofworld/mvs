# 分镜试做 01（草稿）

> 2026-10-23。用户要求“先都试做几个小分镜看下效果”，并要求参考 `Win-Hao/music-mv` 的制作流程。
> 本轮在**画风选定之前**，用同一份镜头描述让三种画风各演四个小镜头，供比较。画风、主角造型、剧情都**仍未确认**。

打开：`npm run dev` 后访问 http://127.0.0.1:5173/shots.html

## 按 music-mv 流程对齐了什么

| 流程要求（`.agents/skills/music-mv`） | 本轮做法 |
| --- | --- |
| 主角写成单独的 `character.js`，所有镜头从这里取（`references/character.md`） | 新增 `character.js`：脚底定位、身高、朝向 left/right/back/front、表情 calm/sad/smile/sleep、走路相位、拿伞、围巾随风；纯函数，有呼吸与眨眼 |
| 每种风格用自己的画法从头画，不套滤镜（`references/styles.md`） | 镜头只给出“纸片/线/天空”的世界坐标描述；纸艺画成带白边、投影、纤维的独立纸片，12 张/秒逐片抖 1–2 px；铅笔为浅底 + 排线 + 每秒抖 12 次的轮廓（填色不抖），光用加色叠；像素在 320×180 索引缓冲上逐格画，30 色固定调色板，人物外描深色像素，走路离散成 4 张，半透明用调色板内混色的光照 pass |
| 一镜一个主要动作，镜头只做一种慢动作，幅度 ≤1.08（`references/transitions.md`） | 每镜只推、只拉或只跟；第 2→3 镜用“推进窗户”换场，约 1 秒 |
| 不硬切、不整屏叠化，换场要有衔接 | 第 2 镜推进到窗玻璃，玻璃里的天空颜色和分界与第 3 镜开场天空一致（有测试） |
| 歌词区约下方 15%，不放脚和关键物 | 测试检查她的脚在歌词带之上（第 3 镜开头从天空下摇的 0.9 秒除外） |
| 画面只由 t 决定、固定种子 | 任意顺序跳转得到同一帧（有测试） |
| 歌词以外不加字 | 画面内无片名、角标 |

与上游的差异（沿用本项目已确认的决定）：歌词仍用 KRC 3 的逐字时间和独立 DOM 层，不改成上游固定间隔弹字；仍是浏览器实时播放，不走 HyperFrames 出 MP4。

## 本机测得的绘制耗时（1920×1080，单帧，2026-10-23）

画面每秒更新 12 次，每帧预算约 83 ms。在本机内置浏览器面板里测了 4 镜 × 8 个时刻：

| 画风 | 各镜平均 | 最慢的一镜 |
| --- | --- | --- |
| 纸艺 | 21–40 ms | 第 4 镜约 40 ms |
| 铅笔 | 34–79 ms | 第 1 镜（雨夜，大面积深色排线）约 79 ms，单帧最高约 100 ms |
| 像素 | 6–12 ms | 第 1 镜约 12 ms |

铅笔夜景已接近预算，整片若选铅笔需要缓存静态层或降低排线密度。只测了这一台机器，未测手机与低配设备。

## 仍是草稿 / 没做的

- 主角造型（短发、灰蓝长外套、锈红围巾）和“他”的样子未经用户确认，也还没有设定图 `character-sheet.png`。
- 四个镜头只是试做，不是全曲分镜；第 1、4 镜在整片里前后的镜头尚未设计。
- 像素风的歌词进了像素对话框，但字仍是页面字体，没有用像素字体。
- 只看了抽样画面和单帧耗时；没有做整段节奏量测（`video_rhythm.py` 针对视频文件，本项目尚无成片）。
