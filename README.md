全部 5 个时间轴及网络原始下载已打包归档，页面可下载并继续切换对照。定稿及当前全部单字动效规则见 [呈现方案记录](docs/词组演绎定稿.md)（文件名为历史遗留）。

已下载并接入4份网络 KRC 时间轴，连同本地自动版可在页面顶部切换，音轨保持连续播放。详情见 [网络歌词版本对比](docs/网络歌词版本对比.md)。其中 KRC 3 是 KRC 1 的整体晚500ms版本，已明确标注。

本地启动：`npm run dev`，打开 http://127.0.0.1:5173 。需要先保留 `analysis/audio/song.m4a`（已从项目 MP4 提取）。

播放器默认使用 `data/project.json` 中选定的 KRC 3（49 句），保留 `data/lyrics.json` 的本地 51 句草稿和其余 KRC 对照。“逐字·轻微动效”与“逐字·原版对照”可切换，两个模式均不合并词组；支持拖动、逐句重听、变速、全曲／单句偏移、浏览器保存与 JSON 导出。正偏移表示歌词更晚，负偏移表示更早。点击歌词行定位到该句前 0.65 秒；空格切换播放，左右方向键跳转 3 秒。

本地自动对齐版保留为对照草稿：其中模型起点及低置信候选不能视为已确认的逐字演唱时间。原始对齐保留在 `analysis/forced-alignment-raw.json`。当前定稿使用用户选定的 KRC 3；音频时钟为唯一依据，暂停／跳转不累积动画时间。

`npm test` 检查歌词覆盖、逐字时间顺序、偏移方向及随机跳转。

逐字校准现已区分每个字的唱入／唱止和画面出现／退场，另有强调强度。下方选择句子后点击单字，可用 20ms 按钮微移、直接输入秒数，或以当前播放时刻记录边界；可循环试听单字与前后 0.4 秒。长音按各自结束时间保持高亮，停顿不保持活动状态。修改和确认状态保存在原有浏览器校准记录中，JSON 导出包括逐字修改及显示区间。

本地自动对齐版的 325 字均已重新计算独立时间候选，没有整句均分回退；仍有低置信和起点估计，不能当作已逐字听验。画面出现／退场是可编辑的编排默认值，与测得的唱音区间分开记录。`analysis/character-timing-review.json` 仅描述这份本地模型基线，不是 KRC 3 的质量评估。
